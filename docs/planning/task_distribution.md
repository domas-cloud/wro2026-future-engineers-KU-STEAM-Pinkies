# Task Distribution

## Principle

Work is divided by subsystem so the team can improve one part of the robot without disrupting the others.

## Suggested Responsibilities

- mechanical work: chassis, steering, drivetrain, wheel mounting, CAD;
- electronics work: wiring, power distribution, sensor integration;
- software work: perception, state logic, control, safety behavior;
- documentation work: README maintenance, file linking, test records, evidence collection.

## Why This Helps

Subsystem-based ownership makes design decisions easier to track and reduces duplicate work.
It also makes it easier to keep the documentation aligned with the real build.
