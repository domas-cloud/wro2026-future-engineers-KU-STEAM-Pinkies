# Rebuild guide

The mechanical files already in [`models/`](../../models/) document much of the steering/drivetrain work, but a complete V2 rebuild is not possible yet because the final battery, motor, driver, PCB files and software are still being finished.

For the final version this page will point to:

- exact BOM and mechanical dimensions;
- printable/CAD parts;
- schematic and PCB manufacturing files;
- connector and GPIO map;
- source code and dependencies;
- build/upload instructions;
- sensor/camera setup;
- steering centre and startup procedure;
- expected bench checks before a track run.

We will test these instructions against the actual final car before calling the rebuild guide complete. The older V1 rebuild material remains in `archivo/` as development history.
