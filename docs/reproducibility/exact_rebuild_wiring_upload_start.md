# Wiring, upload and start procedure

This page will become the short practical setup guide for the final V2 car. The final connector/GPIO map and software build do not exist yet, so we are not filling them with guessed values.

The intended sequence is straightforward: assemble the mechanical car, fit the verified custom PCB and wiring, flash the source from `src/`, check all sensors/camera while stationary, centre the steering, power-cycle once more and start the car with the single physical start input.

Exact commands, pin numbers, calibration checks and expected startup indications will be added when the V2 source and PCB are stable.
