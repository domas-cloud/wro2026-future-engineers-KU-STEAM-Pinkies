# Vehicle Photos

Use this folder for robot photos that document the build and the final vehicle appearance.

WRO expects six vehicle photos showing the robot from different sides and angles, including top and bottom views.

Suggested content:

- chassis overview;
- steering mechanism close-ups;
- electronics mounting;
- sensor placement;
- battery placement;
- iteration comparison photos.

The most useful photos are the ones that clearly show the `MG90S`, `N20`, `L298N`, `BNO085`, `VL53L5CX`, and battery placement relative to the chassis.
