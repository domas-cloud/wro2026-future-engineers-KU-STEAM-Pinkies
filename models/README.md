# Mechanical files

This folder contains the CAD/STL parts used while developing the chassis and steering, including steering-column/gear pieces, linkage bracket, motor-mount parts and shaft spacer. `case.ai` is the plywood case/chassis design file.

Some files were made for the working V1 drivetrain and may need a revision when the final V2 motor and electronics are fitted. We will keep the old geometry if it still fits; otherwise the changed part will be added rather than silently replacing the development history.
