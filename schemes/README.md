# Schematics and PCB files

The existing `Wro_customPCBs.pdf` and older wiring images belong to the Hardware V1 period. We are keeping them because they show how the electronics developed, but they are not the manufacturing files for the V2 custom board.

Hardware V2 will add its final schematic, editable PCB source, Gerbers, drill files, BOM/assembly information and connector/GPIO map here after the design is locked and tested.

See [`custom_pcb_description.md`](custom_pcb_description.md) for the current V2 direction and [`wiring_overview.md`](wiring_overview.md) for the block-level wiring.
